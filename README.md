# 封筒差込印刷

Google スプレッドシートからPDFファイルへの差込印刷プロセスを自動化するGoogle Apps Scriptツールです。このスクリプトはスプレッドシートから複数のPDFファイルを生成し、個人情報が入った封筒やラベルの作成に最適です。

## 機能

- **自動PDF生成**: GoogleスプレッドシートのワークシートをPDFファイルとしてエクスポート
- **バッチ処理**: 1回の実行で複数のPDFを生成（デフォルト：14ファイル）
- **Googleドライブ連携**: 生成されたPDFを指定したフォルダに自動保存
- **カスタマイズ可能なPDF設定**: A4横向きと最適な余白で事前設定済み
- **日本語対応**: 差込印刷ワークフロー向けに設計

## 前提条件

- GoogleスプレッドシートとGoogleドライブにアクセスできるGoogleアカウント
- Google Apps Scriptの基本的な知識
- 次の条件を満たすGoogleスプレッドシート：
  - 「差込印刷」という名前のワークシート
  - スプレッドシートと同じGoogleドライブの場所に「PDF」フォルダ

## セットアップ手順

1. **スプレッドシートの作成**：
   - 新しいGoogleスプレッドシートを作成するか、既存のものを開く
   - 「差込印刷」という名前のワークシートを作成
   - このワークシートに差込印刷テンプレートを設定

2. **PDF出力フォルダの作成**：
   - Googleドライブで、スプレッドシートが保存されているフォルダに移動
   - 「PDF」という名前のサブフォルダを作成（生成されたPDFがここに保存されます）

3. **スクリプトの追加**：
   - Googleスプレッドシートを開く
   - **拡張機能** → **Apps Script** を選択
   - スクリプトエディタのデフォルトコードを削除
   - このリポジトリの `Code.js` の内容をコピー
   - スクリプトエディタに貼り付け
   - プロジェクトを保存（「封筒差込印刷」などの名前を付ける）

4. **スクリプトの承認**：
   - 初回実行時、Googleが権限を要求します
   - 必要な権限を確認して承認してください：
     - Googleスプレッドシートへのアクセス
     - Googleドライブへのアクセス
     - 外部リクエストの実行

## 使い方

1. **データの準備**：
   - 「差込印刷」ワークシートに差し込みたいデータが含まれていることを確認
   - スクリプトはセルA1を使用して異なるグループ番号（1-14）を繰り返し処理します

2. **スクリプトの実行**：
   - Apps Scriptエディタで `exportPDF` 関数を選択
   - **実行** ボタン（▶️）をクリック
   - スクリプトは1から14までの番号が付いた14個のPDFファイルを生成します
   - 各PDFはGoogleドライブの「PDF」フォルダに保存されます

3. **進行状況の監視**：
   - Apps Scriptの実行ログで進行状況メッセージを確認
   - スクリプトは速度制限を回避するため、各PDF生成の間に6秒間一時停止します

## 設定

`Code.js` の以下のパラメータを変更することで、スクリプトの動作をカスタマイズできます：

### PDFの数
配列の長さを変更して、生成するPDFの数を増減できます：
```javascript
for (let groupNum of ([...Array(14)].map((_, i) => i + 1))) {
    // 14を希望する数に変更してください
}
```

### PDF設定
`pdfOptions` 文字列を変更して出力をカスタマイズ：
- **size**: 用紙サイズ（デフォルト：A4）
- **portrait**: 向き（デフォルト：false で横向き）
- **fitw**: 幅に合わせる（デフォルト：true）
- **margins**: top_margin、bottom_margin、left_margin、right_margin（デフォルト：0.1）
- **alignment**: horizontal_alignment、vertical_alignment

### PDF間の遅延
スリープ時間（ミリ秒）を調整：
```javascript
Utilities.sleep(6000); // 6秒、必要に応じて調整
```

## 仕組み

1. スクリプトはアクティブなGoogleスプレッドシートにアクセス
2. 「差込印刷」ワークシートを検索
3. 各繰り返し処理（1-14）で：
   - セルA1を現在のグループ番号で更新
   - 指定された設定でワークシートをPDFとしてエクスポート
   - グループ番号をファイル名としてPDFを「PDF」フォルダに保存
   - 次の処理まで6秒間待機

## トラブルシューティング

**エラー：「'差込印刷'という名前のシートが見つかりません」**
- この名前のワークシートを作成していることを確認してください

**エラー：「'PDF'という名前のフォルダが見つかりません」**
- スプレッドシートと同じGoogleドライブの場所に「PDF」フォルダを作成してください

**PDFが生成されない**
- 実行ログでエラーメッセージを確認
- 必要な権限をすべて承認していることを確認
- スプレッドシートがGoogleドライブに保存されていることを確認

**速度制限エラー**
- `Utilities.sleep()` の遅延時間を増やしてください
